# 文件分类、有效版本与体积治理

## 当前状态

main 基准仍为 `3a7097a0ef154f454e0ce67da0b26c37c26bfed4`。PR #1 是文档/仓库卫生草稿，不含候选模型对象；模型上传仍受 Git LFS 身份缺失阻塞。不得将本说明当作精修已在 main 发布。

## 文件分类与保留规则

|类别|路径|治理原则|
|---|---|---|
|可编辑源|各资产目录的 .blend|保留；模型是源，不用FBX替代；按现有LFS规则存储|
|材质输入|各资产 textures/|保留完整配套；禁止仅按文件名或颜色相似删除|
|导入输出|各资产 fbx/、fbx/split/|派生文件但仍可能是导入入口，不自动删除；候选同步必须对应同一源版本|
|参数与依据|settings.json、README.md、SOURCES.txt、SOURCES.md|保留，实际尺寸/地块未核实项要标明|
|展示与证据|renders/、_audit/|按版本对应；旧图不冒充新候选实际效果|
|生成流程|pipeline/、_pipe/|可能重叠但不凭名称合并/删去，先核对调用及行为|
|本地副产物|Python缓存、Blender数字备份、系统缩略缓存|新增.gitignore仅阻止未来误提交，不删除已跟踪文件|
|可选导出|refined_exports/、fbx7500/（候选包路径）|分别标明版本，不将7500结构回读等同官方FBX2018/游戏验收|

## 只读体积证据

统计对象是首轮+第三轮合并候选，不是 Git 历史体积或游戏内存：734文件，579.18 MB（十进制）。

- 460张纹理423.17 MB（73.1%）；46份blend117.94 MB；177个候选FBX35.02 MB。
- 纹理尺寸：230张1024²、160张2048²、70张4096²。BaseColor244.37 MB＋Normal148.92 MB，占纹理92.9%。
- LOD2纹理共90.93 MB，全为1024²。所有blend内嵌图片数0。
- 基础ZIP443.62 MB＋第三轮ZIP188.87 MB；130文件完全同字节重复，在第三轮压缩数据约160.15 MB。避免两包重复分发比改模型更安全。
- 合并候选内部纹理418个唯一SHA256；42份重复，合计约5.95 MB冗余，均为Emissive。跨资产共享必须先验证引用及导入支持，不能直接删重。

## 安全优化优先级

1. 发一个明确最新的整合包，或只装真正变化文件的增量，减少交付重复。
2. 将候选、归档与有效导出分清，保留单一明确的发布入口。不要为了体积删除用户可能依赖的split导出。
3. 4K图及LOD2纹理可以另做降分辨率候选，经全角度/远近景视觉对比和编辑器验证后决定。减半边长只代表像素量变为1/4，不等于文件或显存同比变化。
4. 不用JPEG替换法线/遮罩；不绕过LFS存储大文件；不重写Git历史。

本轮没有移动、删除或改名任何已跟踪资产，没有改动纹理引用或LFS设置。真实尺寸、材质烘焙、拓扑、LOD预算、CS2 Editor及游戏实测仍不是全部通过。
