# 宾大 Quad Warwick 整段｜连续坡顶、六座老虎窗、双烟囱
**仅 Blender/FBX 离线回读，不是游戏内验收或 pmod。** 解压后把 `QuadWarwickTrial/` 内模型、五类贴图和 `settings.json` 保持同目录；三档主体和两个近中景 Win 窗叠层，无空白 Gls。所有尺寸来自候选模型，不是实测。4×3 地块（32×24米），中心底部枢轴保持，地坪 z=0m，墙面约30×14米，模型门朝−Y。
 
- **远景遮挡与轮廓**：移除两个各自封闭的原屋顶半块，相反法线屋脊同位置重合 160.65 平方米→0。外墙顶部原封盖移除，连续屋顶复用四条墙檐接口的顶点索引。两面单坡在19.55米合脊；细石压顶简化。按近中景恢复前后各三座老虎窗、双烟囱（22.45米，原远档最高19.55米）及模型现有入口的三级台阶。各装饰体仍是分离或交叠网格，不声称整栋为单一闭合物。
- **材质和尺寸**：近中档实际为 2048²（不是源 README 标的 4096²）；远为 1024²。近中档修复 8,538／4,854 个退化 UV 并保持几何、正常 UV 与已用贴图区域。每档顶框仍为32×24米／高22.45米；人体比例与碰撞需进游戏确认。主体三档 13,886／10,178／448 三角，前两档另各202窗三角。远档照明与简化窗材不是近档的逐窗实现。
- **离线验收**：Blender 4.3.2 三档回读无零面积三角和退化 UV。远档探针确认 72 处大坡、150 个老虎窗坡面点、54 个老虎窗窗口、50 个烟囱顶点、15 个台阶点、9 个门面点和4 个地坪角。附件比较图是 Blender，不是游戏画面。
- **仍待 Editor**：先试 Irvine。轮到 Warwick 时与 Ward、Thomas Penn 逐段试摆，检查朝向、接口、地形／碰撞、三级台阶接路、视距切换、夜间与材质。未重做实景连廊、无障碍路线或相邻段的实际拼接。
