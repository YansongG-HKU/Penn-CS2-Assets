# Van Pelt–Dietrich Library 远景主体：闭合接缝候选

原件 48 三角由四个闭合块组成，首层块与主墙块在模型高度约 4.8 m 处各有两片内部盖面，足迹同为 136×34 m，两盖面方向相反、使用不同对角线，并有不足 1 微米的原始高度搭接。此次只焊接这两个等宽块的四对顶点、去掉这四个内部面，不删除地块、错台屋顶或其他接触面；没有冒用旧 40 面草案或修改近中档。

候选 44 三角、28 顶点、66 条双面反向共享边，没有新增开边或非流形边。原 FBX 保留面的逐角 UV、法线、切线和副切线数据不变；回导后 UV 差为 0，几何最大位移 0.954 微米，Blender 导入重算导致的最大法线夹角差 0.00354°。1024×1024 基色、法线、发光图从同目录解码。640×320 正、后、俯三组 BaseColor 对照的二值轮廓像素均无变化，通道最大差 1/255（不代表材质完整渲染结果）。

候选已补局部拓扑，未核实入口、标高和实景形体，未验证游戏内 PBR、近中远切换、接地碰撞。不替换原资产，不发布。

核对 `delta/manifest.json`，用相邻候选的既有重放工具（需要 python-zstandard）从仓库 LFS 原件生成：`python candidates/20261120-three-campus/model_delta.py apply <仓库> <全新输出目录> candidates/20261120-vanpelt-lod2-weld/delta`。把同版本原件的远景 PNG 放在候选 FBX 旁后可回导；`repair_vanpelt_lod2.py` 可从原始 FBX 重作增量对应修复，`verify_vanpelt_lod2.py` 则回导与渲染两件。
