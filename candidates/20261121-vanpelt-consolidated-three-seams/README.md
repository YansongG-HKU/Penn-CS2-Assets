# 宾大 Van Pelt Library · 46 资产整合版的远景接缝试导入包
- 剥除基座、主体分层、阁楼三层的内部重叠面。保留基座与阁楼周围可见外沿，焊接成为一个闭合远景外壳。48→52 三角面，外轮廓尺寸不改；端点焊接小于 0.001 毫米。5 个方向外表面抽检、分方向阵列以及原有 UV/贴图复验见 JSON。
- `assets/VanPeltLibrary/` 包含原整合版近、中景及窗层、修复的远景、10 张原版贴图及仓库同期的原始 settings。只重写 FBX 图片位置以便离线读取。两份零顶点零面的玻璃占位不放进本试验目录，原档案未删。导入时不要引用外层可编辑文件。
- `editable/` 只有此次修复的远景 FBX 对应的可编辑 Blender 文件；不是近景源工程。与 assets 同层保留避免贴图断链。
- 此包沿用原 18×6 候选，现有场地尺寸还未重新注册。此前测绘屋顶、建筑真实进深与台阶是不同方案，不在本包。引擎中 LOD 切换、碰撞、朝向和材质仍未验收，不覆盖已发布版本。
