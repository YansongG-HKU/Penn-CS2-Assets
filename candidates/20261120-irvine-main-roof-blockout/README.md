# Irvine central roof geometric blockout (detached technical reference)

This is a new, detached geometry asset fitted to the previous public 2022 NOAA point-cloud sample. It is not installed, not a replacement for any model and not ready for CS2. The OBJ contains only the central slate roof mass (34 vertices, 64 triangles, 96 paired oriented edges). No side-wing geometry, attached brick walls, windows, spire or textures added. The cap under the roof and small central collar are diagnostic ways to close this standalone asset, not surveyed exterior features.

The raw LOD2 shows a considerably wider, lower octagonal shell. The new object preserves two different radial slope bands for each side measured from the surveyed point cloud; profiles intersect at a common corner-blended geometry. At model-local eave, total east-west width ~17.56 m and north-south ~17.68 m, from repeatable narrow-strip edge samples. Eave positions and 53.175–53.260 m NAVD88 elevations are measured strips, not an exact whole-eave survey. XY origin lies at the LiDAR central high-cluster, axes follow the local orientation measured from the archived photo. OBJ local Z uses 14.4 m NAVD88 as a provisional near-pavement base only, not a sill datum. No scale change to canonical models.

Training excluded entire flight source IDs 19 and 20. Evaluated at true interpolated OBJ top elevation for 349 held-out axial-strip points, side-specific median absolute errors were 0.094–0.154 m and p90 was 0.463–0.666 m. Additional 503 held-out off-axis points in diagonal bands yielded median 0.261 m and p90 0.705 m. Neither validates a finished architectural profile or remaining real roof features. Verified OBJ reimport unchanged by Blender 4.3.2 with fully closed geometry; four CPU views at the same scale and camera separately show old FBX slate roof 16-face extraction and detached blockout. Filename and SHA below identify exact OBJ.

Rebuild with Python (NumPy and SciPy): place roof_blockout.py beside the verified irvine-cropped-points.npz and irvine-roof-plane-fit.json produced by the previous controls package; create a fresh roof-blockout folder and run from that workspace. The OBJ is written with metre coordinates. Use guarded Blender volume for independent preview. Reference mesh SHA-256: ef5facb019b8ebf9a0c2eb1008764cd592a6f6bc53c06253d1e363099f99c44d.
