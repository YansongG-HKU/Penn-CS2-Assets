# Penn LOD2 internal face repair (offline candidate)

Source: Penn draft 8f119449080d9e0d886742fbc2487908c0ea5970. All 46 canonical split far-mesh LFS originals were hash-verified and audited. Irvine and the 34 Quad originals had exact opposite-direction triangle pairs. The separately documented Van Pelt horizontal ring was rediscovered but not changed here.

Follow-up proved a complete congruent opposing border and outward attached faces on opposite sides of the plane for Irvine's spire join and all 34 Quad roof-body seams. For each, all other source triangles were tested for positive coplanar cap overlap or noncoplanar intersection with the open cap interior. The candidate changes Irvine and 33 Quad meshes. McClelland was intentionally left untouched because its exterior needs a separate reconstruction. This is not a claim that other seams or all exterior features have been resolved.

Exactly 144 internal triangles were deleted, including 12 in Irvine (108 to 96); there was no spatial vertex shift or winding change. All remaining edges are closed and oppositely paired. The raw FBX retains the UV, normal, tangent, binormal and smoothing attribute values for all kept corners or faces, with normals converted from vertex indexing to corner indexing. A clean import of all 34 candidates into Blender verified unchanged bounds, retained triangle positions/UVs/material at six decimal digits, and a maximum per-corner normal vector difference below 0.0001; custom normals are quantized during import. Three views each of Irvine and Ashhurst were visually compared in both unlit and lit passes with unchanged source maps: silhouettes and unlit foreground matched; lit 99th percentile at most 1/255 and maximum 11/255 at 32 samples. Texture mapping for renders was explicit. No textures, canonical LFS assets, or already published packages were changed.

Replay with Python and zstandard: run python replay.py /path/to/checkout /path/to/new-output. The checkout must have real LFS binaries for these paths. Each binary delta, input and output SHA-256 and output size are checked. The Irvine result is based on the canonical geometry input; apply this seam fix before the distinct portable-path transform if combining the drafts rather than feeding a portability-modified file to the replay. Textures and game editor import/placement, game LOD transitions and day/night are not validated by this repair.
