# 宾大博物馆 Harrison Rotunda：上屋面东北弧段

用 2024 和 2025 [PASDA 2024](https://imagery.pasda.psu.edu/arcgis/rest/services/pasda/PhiladelphiaImagery2024/MapServer) / [PASDA 2025](https://imagery.pasda.psu.edu/arcgis/rest/services/pasda/PhiladelphiaImagery2025/MapServer) 的航空正射影像核对上盖轮廓。两份同范围的 EPSG:6347 导出为 774×774（0.0762 m 输出像元，非位置精度），图上判读的上盖外缘半径约 4.04 / 4.03 m。影像圆心与测量模型坐标相差 2.97 / 2.36 m，意味着未经高差、摄影和地标控制的绝对坐标不可直接用于建模。轮廓证据只支持判断上盖与外屋面有重叠的投影，不证明连接立面高度、材质或跨年变化。证据包只含相对轮廓和点云摘录，不含原航片。

真正控制几何的是 2022 NOAA EPT 9848 与 2025 费城城市点云中东北方向 45°–90° 的高层回波。将原上盖从半径 3.43 m 延至 3.85 m，焊接约 2.69 m，投影约 1.20 m²。按两个既有锥面中值划分，固定范围共 90 条符合首回波及分组条件的点，其中 74 条高层候选、16 条较低候选；没有再按残差删点。低层仍保留作对照。2025 高程仍是局部经验校准，不是正式基准转换。独立分组回读最大 P95 约 0.234 m，最大单点约 0.363 m。不可把本扇区延伸为完整连接。

三档 FBX 重读，整体三角面 2280 / 1468 / 976，新增 24 / 16 / 12 面。各档旧上盖三角面坐标及 UV 不变，另 9 个物件签名完全不变。共 1560 处验证由共用顶点焊接的边线，各测中央及两侧各 0.5 mm。4361 个三档共同位置验证局部换级差。没有上下屋面直接相接、竖面封闭、碰撞、正式贴图或游戏验收；未替换生产资产或发布。result/ 是本批，prior/ 是前一版；复核 sha256sum -c SHA256SUMS.txt 与 python guard.py verify.py -- "$PWD"。
